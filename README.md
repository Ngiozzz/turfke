# TurfKE

> Book Your Pitch. Play Now.

Find and reserve football turfs across Kenya in seconds. Premium pitches in Nairobi, Mombasa, Kisumu and beyond.

## Tech Stack

- **Next.js 16** — App Router
- **React 19** — Server Components
- **Tailwind CSS 4** — CSS-first config

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
